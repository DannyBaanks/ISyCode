# Prototipos opcionales

Estos scripts M0 exploran loops de agentes contra el checkout externo de
IsyMotron. No forman parte del comando `isycode`, del flujo de CI ni de una
instalación normal.

Requieren configurar `ISYMOTRON_ROOT` y `NVIDIA_NIM_API_KEY`. Al ejecutarlos,
pueden enviar prompts a NVIDIA NIM y generar consumo facturable. Revisa el
código antes de usarlos y no guardes claves en el repositorio.
