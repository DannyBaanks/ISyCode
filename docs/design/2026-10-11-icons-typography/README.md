# ISyCode typography and icon comparator

Accepted visual profile: proposal 1, Ubuntu Sans Mono, Unicode, 14 CSS px, line-height 1.3. The local `preview.html` contains Settings categories, sidebar views, output/text examples, a static Tabler reference and six Its Hover motion adaptations with reduced motion.

This is design material. It does not change the product TUI, install terminal fonts, copy to the system clipboard or verify live integrations. The final browser revision still needs visual/interaction review; browser control was rejected by URL policy on the error-page tab.
