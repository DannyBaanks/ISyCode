## Verification limits this pass

### Verification update — 2026-09-28

- A real Textual render was captured for README screenshots using a temporary
  workspace and static transcript text. No provider, Gateway, MCP tool, or
  shell command was called. The demo deliberately has no read grant, so the
  Files tree exposes the root but does not enumerate its contents.
- The Pyright handshake and semantic broker/Docker witness above were run on
  temporary data. Neither demonstrates authority to inspect or mutate a user's
  real workspace.
- M15 remains incomplete. A live semantic request to the real ISyCo Gateway
  was not made; its workspace identity and local grants are not configured.

- The image is evidence of a plain-text imitation of a `bash` tool call. The
  current request body contains no `tools`/`functions` schema, the SSE parser
  consumes only `content` and `reasoning_content`, and `_run_chat` has no
  dispatch loop. No shell command ran.
- Only the new focused `test_tool_protocol.py` suite was run during this pass.
- No interactive TUI or live provider call was made for this inventory.
