Failure: tests/test_session_search_screen.py::test_action_opens_screen_in_classic_recurring
Observed: after one pilot.pause(), action_open_session_search() did not push
SessionSearchScreen; app.screen remained Screen(id='_default').

Root cause
TUIApp starts workspace initialization asynchronously. The test's single
pilot.pause() did not guarantee that the recurring workspace's session owner
and grants were ready. The action correctly returned while those prerequisites
were absent. Other jobs in that workflow passed: Linux Textual 8, Linux Python
3.10, and Gate evidence.

Regression change
The test waits up to ten seconds for app._sessions_enabled(), invokes the
action, then waits up to ten seconds for SessionSearchScreen to become active.
The helper polls the actual conditions with pilot.pause() bounded to 50 ms.
Application behavior is unchanged.

The test invoked the existing async regression test directly, patched

Inline reproduction:
import asyncio, sys, tempfile
from pathlib import Path
sys.path[:0] = ["tests", "src"]
from _pytest.monkeypatch import MonkeyPatch
from isycode.tui import TUIApp
import test_session_search_screen as test
original = TUIApp._startup_workspace
async def delayed_startup(self):
    await asyncio.sleep(2)
    return await original(self)
async def main():
    monkeypatch = MonkeyPatch()
    monkeypatch.setattr(TUIApp, "_startup_workspace", delayed_startup)
    try:
        directory = Path(tempfile.mkdtemp(prefix="isycode-session-search-test-"))
        await test.test_action_opens_screen_in_classic_recurring(directory, monkeypatch)
        print("DELAYED_STARTUP_TEST=PASS")
    finally:
        monkeypatch.undo()
asyncio.run(main())
