Finding and repair:
  SelfUpdater._env() deliberately gives Git a small environment and forwards
  standard proxy/TLS variables. On Windows it had omitted SYSTEMROOT. Git
  for Windows could not complete a proxied GitHub connection with the reduced
  environment. An A/B check showed that adding only SYSTEMROOT made the same
  git ls-remote request succeed; forwarding the full PATH was unnecessary.
  _env() now forwards SYSTEMROOT (or WINDIR as fallback) only on Windows.
  A Windows-only regression test asserts the value is present.
